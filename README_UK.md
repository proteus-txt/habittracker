# Трекер звичок для Safari — безплатно

Це невеликий адаптивний вебзастосунок, який можна відкрити в Safari на iPhone та додати на домашній екран. Для публікації можна використати GitHub Pages — безплатний статичний хостинг.

## Що вміє
- темний адаптивний інтерфейс;
- додавання, редагування та видалення звичок;
- щоденні відмітки виконання та підрахунок серій;
- статистика за останні 7 днів;
- експорт резервної копії JSON та відновлення з неї;
- кешування оболонки для повторного відкриття без мережі після першого завантаження.

## Важливо про дані
Звички зберігаються локально в Safari на конкретному пристрої. Вони не синхронізуються автоматично з іншими пристроями. Не очищай дані сайтів у Safari, якщо не маєш резервної копії. Експортуй копію кнопкою зі стрілкою вгорі. Щоб **відновити** копію, затисни цю кнопку приблизно на секунду та вибери JSON-файл.

## Публікація безплатно через GitHub Pages (з Windows)
1. Відкрий https://github.com/ і створи безплатний акаунт або увійди.
2. Натисни **+** → **New repository**.
3. Назви репозиторій `zvychky-tracker`. Для найпростішого старту можна вибрати **Public**. Натисни **Create repository**.
4. У репозиторії натисни **Add file** → **Upload files**.
5. Розпакуй ZIP на комп'ютері. Перетягни **всі файли та папки зсередини** папки `habit-tracker-safari` у вікно завантаження GitHub (саму батьківську папку завантажувати не треба).
6. Унизу натисни **Commit changes**.
7. У репозиторії відкрий **Settings** → **Pages**.
8. У блоці **Build and deployment** вибери **Deploy from a branch**; Branch: **main**, folder: **/(root)**; натисни **Save**.
9. Зачекай кілька хвилин. На сторінці Pages з'явиться адреса приблизно такого вигляду: `https://ТВІЙ-АКАУНТ.github.io/zvychky-tracker/`. Відкрий її. Якщо ще не працює — зачекай хвилину та онови сторінку.

## Додати на домашній екран iPhone
1. Надішли собі адресу опублікованого сайту (наприклад, через Telegram, email або нотатки).
2. Відкрий адресу саме в **Safari** на iPhone.
3. Натисни **Поділитися** (квадрат зі стрілкою вгору).
4. Прокрути меню та вибери **Додати на початковий екран** (Add to Home Screen). Якщо пункту немає, прокрути нижче або відкрий меню редагування дій.
5. За бажанням увімкни **Відкривати як вебзастосунок** (якщо така опція показується), потім натисни **Додати**.
6. Запускай трекер новою іконкою з домашнього екрана.

## Оновити застосунок
Завантаж нові версії файлів у GitHub та підтвердь зміни. Якщо iPhone продовжує показувати стару версію, закрий вебзастосунок повністю й відкрий знову; іноді оновлення кешу займає трохи часу.

## Нотатки
- Публікація на GitHub Pages безплатна для публічних репозиторіїв; умови GitHub можуть змінюватися.
- Це вебзастосунок, а не застосунок з App Store.
- Вебзастосунок не надсилає дані на сервер; GitHub Pages хостить лише файли інтерфейсу.
